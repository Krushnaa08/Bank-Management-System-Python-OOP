# 🏦 Bank Management System (Python OOP)

A Bank Management System developed in Python using Object-Oriented Programming concepts.

## Features

- Create Saving Account
- Create Current Account
- Deposit Money
- Withdraw Money
- Interest Calculation
- Transaction History
- Customer Management
- Bank Management

## OOP Concepts Used

- Classes & Objects
- Encapsulation
- Inheritance
- Method Overriding
- Abstract Classes
- Composition
- Polymorphism
